# Classification-with-KNN-for-diabetes-patients
The goal of this project is to analyze patient data and identify patterns that can improve the early detection of diabetes. Using historical medical records and diagnostic measurements, we aim to build a predictive model that classifies patients into two categories: diabetes or no diabetes.

To achieve this, we apply the K-Nearest Neighbors (KNN) algorithm, a simple yet effective machine learning method. KNN classifies a patient based on the similarity of their medical data to that of other patients. By comparing features such as glucose levels, BMI, and other health indicators, the model predicts whether a patient is likely to have diabetes.

This approach demonstrates how machine learning can support healthcare professionals in making data-driven decisions and improving diagnostic accuracy.
